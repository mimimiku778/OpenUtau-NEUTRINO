# 1 行に 1 つ、「 | 」区切り: <key> | <誰の物か> | <題> | <これまで> | <この版> | <本家 master 向けのブランチ> <その先頭のコミット (40 桁)>
# - key は extra-commits.txt・extra-commits-latest.txt の 3 列目と合わせる。「足したコミット」の表の「固定版」「最新版」の列は、その key のコミットを集めて作る
# - 「この版」が空なら「足した機能」の表には載せず、「足したコミット」の表にだけ載せる

# - README にだけ載せる詳しい説明 (何ができる・どこで設定・こうするとこうなるの表・図) は packaging/features/<key>.md。あれば表の題からそこへ飛べる
