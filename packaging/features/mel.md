ずんだもん等の NEUTRINO v3 の声でも、カーブ `GENC`(声色)・`TENC`(明るさ・強さ)が効きます。

**どこで**: ピアノロール下のカーブ欄。左の `GENC`・`TENC` を押して選び、描く。値は −100〜100、0 で変化なし。

**画面**: `GENC` を選んで(左の赤丸)、カーブを描いた所(赤枠)。音符は触らない。

<img src="docs/mel-genc.webp" width="560" alt="ピアノロール下の GENC の欄にカーブを描いた画面">

<br>

**こうすると → こうなる**(同じ句を値だけ変えて書き出し、実測)

| カーブ | 値 | こうなる |
|---|---|---|
| `GENC` | −40 | 細く若い声。声の山 ×1.32(+4.9 半音) |
| `GENC` | −20 | 声の山 ×1.14(+2.2 半音) |
| `GENC` | +20 | 声の山 ×0.86(−2.6 半音) |
| `GENC` | +40 | 太く低い声。声の山 ×0.76(−4.7 半音)。200 Hz 付近にも音が出る(+15 dB) |
| `TENC` | −100 | 小さく暗く。音量 −7.2 dB、高い方 −3.0 dB/oct |
| `TENC` | −50 | 音量 −3.7 dB、高い方 −1.5 dB/oct |
| `TENC` | +50 | 音量 +3.7 dB、高い方 +1.6 dB/oct |
| `TENC` | +100 | 大きく明るく。音量 +7.3 dB、高い方 +3.2 dB/oct |

- `GENC` は声の高さを変えずに、声の山(フォルマント)だけを動かす。+ で下げて太く低い声、− で上げて細く若い声。向きは本家 OpenUtau の決まりどおり(100 で 12 半音下)。
- `TENC` は全体の音量と、1 kHz を軸にした高い方の傾きが一緒に動く。
- 効きが強いので、`GENC` は ±10〜20、`TENC` は ±20〜50 から。

**図**: 上の表の実測(句全体の平均スペクトル)。左は `GENC` で、声の山が − で右(高く)・+ で左(低く)へ動く。右は `TENC` で、線全体が上下し、右肩の傾きが変わる。
